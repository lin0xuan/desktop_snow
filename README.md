# desktop_snow

Windows 桌面积雪。雪花落在窗口上沿，堆成带斜边的雪堆；上面的窗口会挡住下面的窗口，露出来的边仍然可以积雪。最大化窗口的上沿不积雪。没有窗口挡住的雪会落到屏幕最底部，任务栏不会挡住。

拖动窗口时，积雪会按惯性甩掉一部分；拖得又快又远可以全部甩掉。鼠标放在雪堆上会把雪拨乱。屏幕最底部的积雪会由一辆小铲车定时从左到右铲掉。

## 运行

需要 Windows、Python 3.11+，以及 Pillow、numpy。

    pip install -r requirements.txt
    python -m snowdesk

也可以运行 start-snowdesk.ps1。

Ctrl+Alt+Q 退出，并恢复原来的壁纸。

## 说明

积雪按落沙的安息角塌成斜边。窗口边缘堆不住的雪会掉下去；雪堆顶到屏幕上边时，会被挤到两边再掉落。
